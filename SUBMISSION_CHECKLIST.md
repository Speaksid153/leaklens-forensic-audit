# Hackathon submission checklist

## Required links

- [ ] Public deployed application opens without credentials.
- [ ] Public GitHub repository contains visible commit history.
- [ ] Public demo video is no longer than three minutes.
- [ ] Public Google Doc covers the track, problem, and technical stack.

## Viability gate

- [ ] The core audit flow works from an incognito browser.
- [ ] The deployed application matches the repository and demo.
- [ ] All four submitted links remain publicly accessible.

## BlockseBlock

- [ ] Create the project from the BlockseBlock dashboard.
- [ ] Use project name **LeakLens** and track **Building Evals**.
- [ ] Add all mandatory links and select **Submit Now**.
- [ ] Accept both required notes and select **Continue**.
- [ ] Select **Final Submit** only after the irreversible final review.
- [ ] Verify **My Projects** displays **Submitted**, not Draft.
- [ ] Save a screenshot of the submitted status.
